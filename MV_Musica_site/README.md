# MV Downloader

Aplicacao web local para baixar midia por URL e converter para MP3/M4A/MP4.

## Windows
1. Abra PowerShell na pasta.
2. Execute: `powershell -ExecutionPolicy Bypass -File .\instalar_windows.ps1`
3. Depois: `npm start`
4. Abra `http://localhost:3030`

## Dependencias
- Node.js 18+
- yt-dlp
- FFmpeg

## Uso responsavel
Use apenas com conteudo proprio, autorizado, em dominio publico, ou quando o servico permitir o download. O aplicativo nao remove DRM nem quebra protecoes de acesso.
