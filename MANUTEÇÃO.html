⚡ Terminal de Comandos · Windows

Diagnóstico, reparo e manutenção — todos os comandos essenciais para estabilidade e performance.

admin@defender

🛡️ Antivírus (Defender)
Atualizar assinaturas de vírus
admin~$ Update-MpSignature
Verificação rápida do sistema
admin~$ Start-MpScan -ScanType QuickScan
Verificação completa
admin~$ Start-MpScan -ScanType FullScan
Escanear pasta de Downloads
admin~$ Start-MpScan -ScanPath "C:\Users\Seu\Downloads"

admin@status

📊 Status & Monitoramento
Status geral do Defender
admin~$ Get-MpComputerStatus
Listar ameaças encontradas
admin~$ Get-MpThreat
Histórico de detecções
admin~$ Get-MpThreatDetection
Últimos 50 erros do sistema
admin~$ Get-WinEvent -LogName System -MaxEvents 50 | Where-Object { $_.LevelDisplayName -eq "Erro" } | Format-List TimeCreated, Message

admin@reparo

🔧 Reparação do Windows
Verificar e reparar arquivos do sistema
admin~$ sfc /scannow
Reparar a imagem do Windows (DISM)
admin~$ DISM /Online /Cleanup-Image /RestoreHealth
DISM com fonte oficial (reparo avançado)
admin~$ DISM /Online /Cleanup-Image /RestoreHealth /Source:https://www.microsoft.com/software-download/windows11 /LimitAccess
⚠️ Troque windows11 por windows10 se for o caso.
Reiniciar o PC imediatamente
admin~$ shutdown /r /t 0

admin@disco

💾 Diagnóstico de Disco (SSD/HDD)
Ver saúde dos discos físicos
admin~$ Get-PhysicalDisk | Select FriendlyName,HealthStatus,Size
Verificar sistema de arquivos (C:)
admin~$ chkdsk C: /scan
Corrigir erros lógicos (C:)
admin~$ chkdsk C: /f
Verificar e reparar setores defeituosos (C:)
admin~$ chkdsk C: /r
⏳ Requer reinicialização. Execute e digite Y para agendar.

admin@avancado

🔬 Diagnóstico Avançado
Teste de memória RAM (diagnóstico)
admin~$ mdsched
🔄 Reinicia o PC e executa o teste — aguarde a conclusão.
Limpeza profunda de arquivos temporários
admin~$ cleanmgr /sageset:1 && cleanmgr /sagerun:1
📋 O primeiro comando abre a configuração; marque todas as opções e OK.
Desfragmentar unidade (apenas HDD)
admin~$ defrag C: /O
❌ NÃO use em SSD — o Windows já otimiza automaticamente (TRIM).
Listar drivers de terceiros instalados
admin~$ Get-WindowsDriver -Online | Where-Object { $_.ProviderName -notlike "Microsoft*" } | Select-Object Driver, Version, Date
🔧 Drivers antigos podem causar instabilidade — atualize pelo fabricante.

admin@manutencao

⚙️ Manutenção & Otimização
Instalar e aplicar todas as atualizações do Windows
admin~$ Install-Module PSWindowsUpdate -Force; Get-WindowsUpdate -Install -AcceptAll -AutoReboot
⬇️ Instala o módulo (se necessário) e baixa/instala todas as atualizações.
Reiniciar serviços essenciais do Windows
admin~$ Restart-Service -Name wuauserv, bits, cryptSvc, trustedInstaller
Verificar temperatura dos componentes
admin~$ Get-WmiObject -Namespace "root\wmi" -Class MSAcpi_ThermalZoneTemperature | Select-Object CurrentTemperature
🌡️ Divida o valor por 10 para obter °C. Acima de 80°C, limpe os coolers.
Executar SFC após DISM (recomendado)
admin~$ sfc /scannow
🔁 Execute sempre após um DISM para garantir a correção total.
